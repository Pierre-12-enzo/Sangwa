## 🎯 About the Project

**Sangwa Polyclinic** is a private healthcare facility located in Ngoma Sector, Huye, Rwanda. Founded in late 2023 near CHUB (University Hospital of Butare), the clinic specializes in maternity care, pediatrics, internal medicine, and gynecology — with a vision to become a premier regional teaching and international healthcare center.

This project is a **production-grade web prototype** designed to:
- Establish a professional digital presence for the clinic
- Provide patients with easy online appointment booking
- Showcase the clinic's services, facilities, and medical expertise
- Reduce reception desk congestion by digitizing appointment requests
- Build trust with a modern, accessible, and mobile-first user experience

> 💡 **Note:** This is Phase 1 of a two-phase project. Phase 2 includes a full patient portal with a secure Node.js/Express + MongoDB backend, SMS confirmations, and an admin dashboard for clinic staff.

## ✨ Features

### 🎨 User-Facing Features
- **Animated Hero Section** — Full-screen parallax hero with GSAP-powered entrance animations
- **Live Stats Counter** — Scroll-triggered animated counters showcasing clinic achievements
- **Services Grid** — Interactive 3D hover cards for all medical specialties
- **Facility Gallery** — Lightbox-enabled image gallery of the clinic's facilities
- **Patient Testimonials** — Auto-playing Swiper.js carousel with real patient stories
- **Appointment Booking Modal** — Interactive form with validation and success states
- **Floating Action Buttons** — Quick-access WhatsApp, Call, and Booking buttons
- **Google Maps Integration** — Embedded map showing clinic location in Huye
- **Fully Responsive** — Optimized for mobile, tablet, and desktop
- **Smooth Scrolling** — Buttery-smooth navigation between sections

### ⚡ Technical Features
- **Lightning-fast Performance** — Vite 5 + React 18 with optimized builds
- **Zero-Config Styling** — Tailwind CSS v4 with custom design tokens
- **Cinematic Animations** — GSAP 3 + ScrollTrigger for premium motion design
- **Glass Morphism UI** — Modern backdrop-blur effects throughout
- **Custom Scrollbar** — Branded scrollbar matching the clinic's color palette
- **Accessibility-First** — Semantic HTML, ARIA labels, and keyboard navigation
- **SEO-Ready** — Meta tags and structured data prepared

## 🎨 Design System

The color palette was carefully extracted from the **physical facade and signage** of Sangwa Polyclinic to ensure brand consistency between the digital and physical experience.

| Role | Color Name | HEX Code | Usage |
|------|------------|----------|-------|
| **Primary** | Deep Teal / Sage | `#3B6B66` | Navbar, primary buttons, headlines |
| **Accent** | Warm Medical Orange | `#E06D20` | CTAs, badges, highlights |
| **Secondary** | Healthcare Green | `#1E6B43` | Icons, success states |
| **Background** | Soft Neutral White | `#F8FAFC` | Page backgrounds, cards |
| **Dark** | Deep Slate | `#0F172A` | Body text, footer |

Typography uses **Inter** — a clean, highly legible sans-serif designed specifically for screen readability.
